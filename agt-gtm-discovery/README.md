# AGT GTM Discovery

AGT GTM Discovery is a structured interview skill for pressure-testing GTM, Marketing Operations, RevOps, AI enablement, systems transition, and fractional engagement plans.

It asks one question at a time, provides a recommended answer, distinguishes confirmed facts from assumptions and unknowns, and produces a decision log with owners, dependencies, system inventory, and prioritized 30/90-day actions.

## Install

This repository is public. Install the skill with:

```bash
npx skills add https://github.com/All-Great-Things-Inc/agt-gtm-discovery --skill agt-gtm-discovery
```

## Use

Invoke the skill explicitly with `$agt-gtm-discovery`, then provide the relevant roadmap, meeting summary, proposal, transcript, or workspace documents.

Use an approved AI environment for confidential business information. Do not provide passwords, API keys, or unnecessary personal data.
