# AGT-GTM-Discovery

AGT-GTM-Discovery is an All Great Things interview skill for pressure-testing
GTM, Marketing Operations, RevOps, AI enablement, systems transition, and
fractional engagement plans.

It asks one question at a time, provides a recommended answer and rationale,
separates confirmed facts from assumptions and unknowns, and produces a
decision log with owners, dependencies, system inventory, and prioritized
30/90-day actions.

## Install

This repository is public. Install the skill with:

```bash
npx skills add https://github.com/All-Great-Things-Inc/agt-gtm-discovery --skill agt-gtm-discovery
```

## Use

Invoke it explicitly with `$agt-gtm-discovery`, then provide the relevant
roadmap, meeting summary, proposal, transcript, or workspace documents.

The skill is designed to preserve the user's decision ownership and does not
take external actions unless separately authorized.

## Security

- Use the skill only in an approved AI environment.
- Do not provide passwords, API keys, credentials, or unnecessary personal data.
- Do not place confidential client materials in this repository.
- Use client-owned accounts and approved systems for production work.
